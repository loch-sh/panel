# Web hosting

Optional plugin letting admins create web sites from the panel. Each site is a plain Docker Compose project generated by the API in `<HOSTING_STACKS_DIRECTORY>/hosted-<name>/` (`compose.yaml`, `config/php.ini`, `config/vhost.conf`).

The compose file is the source of truth: the panel settings are stored in its `x-loch` section, so a site boots with `docker compose up -d` even without the panel.

Templates use the webdevops images: `php-nginx` and `php-apache` (PHP 5.6 to 8.5), `nginx`, `apache`.

## Configuration

These variables are not in `.env.example`: add them to `.env`.

| Variable | Description | Default |
|---|---|---|
| `HOSTING_ENABLED` | Enables the plugin | `false` |
| `HOSTING_STACKS_DIRECTORY` | Compose projects directory (may be shared with CI stacks) | `/data/compose` |
| `HOSTING_SITES_DIRECTORY` | Site data directory (usually the SFTPGo directory) | `/data/websites/hosted` |
| `HOSTING_TRAEFIK_NETWORK` | External Docker network joined by the web services | required |
| `HOSTING_TRAEFIK_HTTP_ENTRYPOINT` | Traefik HTTP entrypoint | `web` |
| `HOSTING_TRAEFIK_HTTPS_ENTRYPOINT` | Traefik HTTPS entrypoint | `websecure` |
| `HOSTING_TRAEFIK_CERTRESOLVER` | Traefik certificate resolver (empty: default certificate) | `letsencrypt` |
| `HOSTING_RUN_UID` / `HOSTING_RUN_GID` | Owner of the site directories created by the panel | `1000` |
| `HOSTING_DEFAULT_MEMORY_MB` / `HOSTING_DEFAULT_CPUS` | Default limits of a site (0: unlimited) | `0` |
| `HOSTING_MAX_MEMORY_MB` / `HOSTING_MAX_CPUS` | Highest limits a site may request (0: the host's) | `0` |

## Deployment requirements

The server refuses to start without them:

- both directories exist, are writable, and are bind-mounted **at the same path** in the API container (`-v /data/compose:/data/compose -v /data/websites/hosted:/data/websites/hosted`);
- the Docker socket is mounted and `docker compose` is available (included in the image).

The Traefik network is not checked at startup: if it is missing, deployments fail.

## Networks

A site joins [private networks](networks.md) through its `networks` setting (registry names, kept sorted; `x-loch.networks` in the compose file, `SpecVersion` 6, which replaces the former `servicesNetwork` option). It reaches the managed service instances of the networks it shares with them by their name (`svc-postgres-17`, `svc-redis-cache`...): see [Managed services](services.md#connecting-a-site).

- **Default**: when the services module is enabled, `GET /hosting/config` returns `defaultNetworks: ["services"]` for the interface and the CLI to preselect the system network `services` on a new site; the API itself takes the list it is given. Existing sites keep their networks.
- **Validation**: a network must exist in the registry and be the one the panel created (`INVALID_HOSTING_NETWORK`, field `networks`). A network the site already has is not checked again when the site is updated (rendering still requires it to be registered).
- **Rendering**: each network is an `external` network of the compose file, with its `docker network create` command in the header so that the site boots without the panel.
- **Changing**: through the site update (`networks` in `PUT /hosting/stacks/{name}`, `loch hosting update --network`) or from the network page (attach/detach). The change redeploys the site like any update: the web container is recreated, a few seconds of downtime.
- A site on any panel network loses `NET_RAW`.

## Safety

- The API only touches `hosted-*` directories whose compose file it generated: CI stacks in the same directory are never modified.
- It refuses symlinks and writes atomically.
- It checks new names against existing directories, compose projects, containers, Traefik routers, routed domains and sites.
- It detects manual edits of the compose file: an update then requires `force=true`.
- Containers run with `no-new-privileges` and without published ports. Sites on a panel network also lose `NET_RAW`.
- PHP modules are disabled with `PHP_DISMOD` (`ioncube` by default).

The routes are listed in the [API reference](api.md#web-hosting).
