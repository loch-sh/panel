# Security

The security documentation lives in the API repository:

- [Security](host-panel-api/docs/security.md): authentication, authorization, CSRF, HTTP hardening, storage, audit trail.
- [Managed services security](host-panel-api/docs/services-security.md): tenant isolation and hardening of the databases, caches and message brokers.

If you discover a vulnerability, report it privately to the maintainers rather than opening a public issue.
